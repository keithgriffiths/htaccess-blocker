# Changelog

## 2.0.0 - 2026-10-10

- Replace duplicate and legacy bot-filter directives with a small Apache 2.4 rewrite snippet.
- Remove bundled WordPress-generated rewrite block to avoid accidentally replacing site rules.
- Add optional sensitive-file hardening example.
- Expand installation, validation, compatibility and rollback documentation.

## Historical

The original repository README reported 2017 as its last update; its `.htaccess` header indicated 2020. The v2.0 release replaces these older examples rather than claiming they are current.
